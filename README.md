# Interactive Site Plan - Property Marketing Application

A web-based visual application designed for the property marketing team and potential buyers. This application provides an interactive map of the property development, allowing users to explore available units, view floor plans, check prices, and see the real-time status of each unit (e.g., Available, Booked, Sold).

The primary goal of this project was to replace static brochures and physical models, providing the sales team and clients with accurate, up-to-the-minute information.

![-----------------------------------------------------](https://raw.githubusercontent.com/andreasbm/readme/master/assets/lines/rainbow.png)

## ✨ Key Features

* **Interactive Map:** Users can easily zoom, pan, and click on any lot or unit on the site plan.
* **Real-Time Unit Status:** Unit colors change dynamically according to their availability status (e.g., green for available, yellow for booked, red for sold).
* **Detail Pop-up:** Displays detailed information such as unit type, land/building size, price, and floor plan when a unit is clicked.
* **Filter & Search:** Allows users to filter units by type, number of rooms, or price range.
* **Admin Panel:** A dedicated interface for the sales/admin team to update unit statuses directly from the system.
* **Responsive Design:** Fully accessible on both desktop and mobile devices (tablets/phones).
